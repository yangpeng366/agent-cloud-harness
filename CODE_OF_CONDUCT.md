# Code of Conduct

## Our Standard

This project is intended to be practical, respectful, and reviewable.

Examples of positive behavior include:

- focusing discussion on code, product behavior, and evidence
- giving concrete reproduction steps and test notes
- challenging ideas without attacking people
- documenting tradeoffs clearly when proposing changes

Examples of unacceptable behavior include:

- personal attacks
- harassment or discriminatory language
- intentionally disruptive behavior
- publishing private or sensitive information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate these standards.

## Scope

This Code of Conduct applies in repository discussions, issues, pull requests, and other project-managed communication channels.

## Reporting

If a discussion becomes abusive or unsafe, contact the maintainers through the repository’s available contact path and include links or screenshots where possible.
